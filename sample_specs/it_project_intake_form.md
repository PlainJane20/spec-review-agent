# IT Project Intake Form - MVP Version

## Form Title
**IT Project Request**

## Form Description
Submit your IT project, enhancement, or feature request. IT Leadership reviews all submissions weekly.

---

## 10 Essential Questions

### 1. Project Name *
**Type:** Short answer
**Question:** What is your project called?

---

### 2. Request Type *
**Type:** Multiple choice
**Question:** What type of request is this?
**Options:**
- Project Request (large initiative, multiple features)
- Feature Request (new capability)
- Enhancement Request (improve existing system)
- Bug Fix
- Support/Help Request

---

### 3. Your Name & Email *
**Type:** Short answer
**Question:** Your name and email (so we can follow up)
**Example:** Jane Smith, jane.smith@company.com

---

### 4. Department *
**Type:** Short answer
**Question:** Which department are you in?

---

### 5. What Problem Are You Solving? *
**Type:** Paragraph
**Question:** Describe the problem or pain point this project addresses. Why is this needed?

---

### 6. Business Impact *
**Type:** Paragraph
**Question:** What value will this create? (e.g., save $X, save Y hours/week, increase revenue, reduce risk, improve customer satisfaction)

---

### 7. What Will Be Delivered? *
**Type:** Paragraph
**Question:** What is the expected outcome or product when this is complete?

---

### 8. Target Completion Date *
**Type:** Date
**Question:** When do you need this completed?

---

### 9. Priority Level *
**Type:** Multiple choice
**Question:** How urgent is this?
**Options:**
- P0 - Critical (business-stopping, immediate)
- P1 - High (needed this quarter)
- P2 - Medium (needed in 1-2 quarters)
- P3 - Low (nice to have, no deadline)

---

### 10. Budget Status *
**Type:** Multiple choice
**Question:** Is there budget allocated for this?
**Options:**
- Yes, budget approved ($_____ - fill in amount)
- Budget pending approval
- No budget yet
- Unsure / Need IT to estimate

---

Your IT project request has been submitted.

## Google Sheet Assessment Columns

After creating the form, add these columns to the Google Sheet:

1. **Timestamp** (auto-generated by Google Forms)
2. **Project Name** (from form)
3. **Request Type** (from form)
4. **Requestor** (from form)
5. **Department** (from form)
6. **Problem** (from form)
7. **Impact** (from form)
8. **Deliverables** (from form)
9. **Target Date** (from form)
10. **Priority** (from form)
11. **Budget Status** (from form)
12. *(Add these manually)*
13. **IT Recommendation** (Approve / Reject / Defer / Need Info)
14. **Estimated Effort** (Small / Medium / Large)
15. **Target Quarter** (Q2 2026 / Q3 2026 / Q4 2026 / Backlog)
16. **IT Notes**
17. **Decision Date**
18. **JIRA Epic Link** (add after creating Epic)

---

## How to Build This Form (5 Minutes)

1. Go to https://forms.google.com
2. Click **+ Blank form**
3. Add the title and description
4. Add 10 questions from above (copy/paste text)
5. Mark questions 1-9 as **Required**
6. Click **Send** → Get shareable link
7. Share link with stakeholders

**Done!**

---

## Example Submission Flow

**Stakeholder fills out form:**
- Project: "Add SSO login"
- Type: Enhancement Request
- Problem: "Users have too many passwords, security risk"
- Impact: "Save 500 employees 5min/day = 40 hours/week"
- Priority: P1 - High
- Budget: Yes, $25K approved

**IT Leadership reviews in sheet:**
- Recommendation: Approve
- Effort: Medium (3-4 sprints)
- Target Quarter: Q3 2026
- Notes: "Need to coordinate with Security team"

**TPM creates Epic in JIRA:**
- Epic Name: "SSO Login Integration"
- Description: Copy details from intake form
- Status: APPROVED → IN_ROADMAP (Q3 2026)
- Link back to Google Form submission

**Team executes:**
- Break Epic into Stories
- Stories go through BRD process
- Pull into Sprints
- Build and ship!
